# Personal Portfolio Website

A clean and responsive personal portfolio website designed to showcase skills, projects, and biographical information. This project is built using semantic HTML5 and CSS3.

## Installation
Follow these steps to run the project on your system:

 **Download or Clone the Repository**
git clone <your-repo-link>

**Open the Project in Visual Studio Code**
* Open VS Code
* Go to **File → Open Folder**
* Select the project folder 

**Check All Files**
* index.html
* about.html
* projects.html
* style.css
* docs folder
* assets folder

**Open the website**
* Right-click index.html
* Click "Open with Live Server"
* OR double-click index.html to open it in any browser

**Usage**
* You can browse through the different pages of the website:

Home Page:
* Shows your introduction and profile picture.

About Page:
* Displays information about you and the purpose of the assignment.

Projects Page:
* Contains a list of projects (including this portfolio website).

**This project is created to demonstrate:**
* HTML & CSS skills
* Using VS Code for development
* Using Git commands (init, add, commit, push)
* Hosting the repository on GitHub
* Writing documentation using Markdown

## 🚀 Features

* **Responsive Design:** Optimized for different screen sizes using the viewport meta tag.
* **Navigation:** Simple, intuitive navigation bar linking to Home, About, and Projects.
* **Hero Section:** Prominent introduction area with a profile image.
* **Clean Structure:** Semantic HTML tags (`<header>`, `<nav>`, `<section>`, `<footer>`) for better accessibility and SEO.

## 🛠️ Technologies Used

* **HTML5:** For the structural backbone of the website.
* **CSS3:** For styling, layout, and responsiveness (linked via `style.css`).
